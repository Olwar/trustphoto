# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, stay on the subject, and accept that other people see
things differently. No harassment, no personal attacks, and no publishing of
another person's private information.

This applies in the issues, pull requests and discussions of this repository.

To report a problem, write to **hello@socialhuman.dev**. We read every report,
we keep the reporter's name private, and we answer within five working days.
The maintainers may remove comments, commits and issues that break these
rules, and may block a person who keeps breaking them.
